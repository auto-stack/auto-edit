~362ms 几乎全部是 auto.exe 宿主层 + VM 解释装载——**release 直拉把它
消掉了**，这正是 L2 门控链设计 release 产物直拉的依据实证。

## 预算断言终态（全 10 行，l2 语义）

| 状态 | 行 |
|---|---|
| **armed（pass）** | steady_start：**12.7ms ≤ 80ms**（spawn→ws_loaded 代理口径+注记） |
| armed-record | renderer_cold_start：16.9ms 单列（预算 pending-Q2） |
| pending-feature | warm_start（M2）/ installer（Q2） |
| arch-blocked（附 L2 数字锚点） | open_100mb（40.6ms）/ open_1gb（无 fixture，缺省） |
| blocked-upstream | type_latency / scroll_fps（内核帧插桩）、diff_100mb（M3） |
| ledger（附 L2 数字） | idle_mem：app ~25.8MB 均值（rqhost 守护 68.9MB 单列另记，预算随 Q2） |

退出码 0；armed pass 为记录性判定（首基线锚点；硬门禁「回归当天修」
语义属 M4 门禁生效后，战略补注 6(d)）。
